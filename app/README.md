# Shift Booking Mobile App (Expo SDK 58)

The React Native mobile client for the Kiran Foundation Shift Booking Assignment.

## 🛠️ Stack
- **Expo SDK 58** (React Native 0.88.1, React 19.3.0)
- **TypeScript** (Strict mode)
- **TanStack React Query v5**
- **React Navigation v7** (Bottom Tabs)
- **react-native-svg** (Vector animations)

## 🚀 Running the App
```bash
# 1. Install dependencies
npm install

# 2. Start Expo Metro bundler
npx expo start
```

- **Physical Phone**: Scan the terminal QR code with **Expo Go**. The app automatically detects your computer's IP address dynamically.
- **Android Emulator**: Press `a` in the terminal to launch the app on the running emulator. Run `adb reverse tcp:8080 tcp:8080` to tunnel the mock API.
